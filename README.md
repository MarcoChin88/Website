# Website

Live site: [https://marcochin88.github.io/Website/](https://marcochin88.github.io/Website/)

Static GitHub Pages boilerplate for Junipri.

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy to GitHub Pages

1. Push this repo to GitHub.
2. **Settings → Pages → Build and deployment**
3. Source: **Deploy from a branch**
4. Branch: `main` / folder: `/` (root)
5. Site URL: [https://marcochin88.github.io/Website/](https://marcochin88.github.io/Website/)

## Customize

| File | Purpose |
|------|---------|
| `index.html` | Markup & copy |
| `css/styles.css` | Theme & layout |
| `js/main.js` | Client scripts |

CSS variables in `:root` control colors and fonts.
