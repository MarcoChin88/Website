About

This site is static HTML, CSS, and a little JavaScript. Push it to a GitHub repository, turn on Pages from the main branch root, and it goes live at *.github.io.

Get started

  1. Edit index.html, css/styles.css, and js/main.js.
  2. Commit and push to main.
  3. In the repo: Settings → Pages → Deploy from a branch, choose main / / (root).
